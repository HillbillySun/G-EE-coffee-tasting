# 口吻和示例

## 口吻特点

| 表达习惯 | 写新豆子时怎么用 |
| --- | --- |
| 磨粉写花香，注水写果香和香料，喝到低温又回头看花香和酸甜 | 以实际记录的阶段为顺序。一个味道反复写时，顺手交代它在这一口更幽、更显，或和什么味道在一起。 |
| 从李子、清酒、花香一路写到白衬衫和钟鼎之家 | 香气细、入口干净、花香幽，这些体验一起撑住「白衬衫」的联想。借一个形象说完这种气质，再回来写酒香、李子或花香。 |
| 同一个词反复回来，有时前面还叠着「极度」或「超级无敌」 | 让短句和长串交替。「白桃，白桃」之后，可以接一句桃肉的软甜，或写它在茶汤里的感觉。 |
| 风味有颜色、光和触感。写白色的酸、霜感红葡萄、奶呼呼 | 颜色随风味和强弱变化，触感随已知的口感变化。「暖」「冷」可以形容甜的感觉，实际杯温按输入写。 |
| 白葡萄酒、甜点、香水、茶、室内暖气和海风会出现在同一篇里 | 挑一两个能说清差异的跨感官联想。联想越具体，越要贴住杯里的线索。 |
| 夸张地赞叹，也承认苦、酵和掐喉感 | 允许喜欢和嫌弃发生在同一口，保留用户记下的持续时间与强弱。 |
| 感叹、反问、零碎英语、顺手记参数和感谢朋友 | 感叹和英语跟着情绪走。参数与人情按用户的真实素材自然插入。 |

## 风味怎么接着往下写

按这支豆子的酸甜、香气和口感挑方向。段落之间可以用同一个味道的不同侧面接过去。例如茉莉接麝香葡萄的花气，葡萄和白桃都水润却一个亮、一个软，白桃的软甜又接得住白茶。开头和收尾都可以提茉莉，前面说花香的样子，结尾说整杯最惦记的是什么。

| 原有风味 | 可以往哪里想 |
| --- | --- |
| 茉莉花、白茶 | 白花的幽香可以想到栀子花苞、玉兰和淡淡的茉莉银针。茶感可以想到茶汤里的清甜、梨皮和一点干草香。 |
| 白桃、麝香葡萄 | 可以顺着水果的水润感想到水蜜桃、香梨、荔枝水、霜感白葡萄。沿香气可以联想到麝香葡萄汁、白葡萄软糖和一口白葡萄酒。 |
| 蜜橘、西柚 | 蜜橘从果汁往橘皮糖、橙花蜜和汽水走。西柚从果肉的酸往柚皮微苦、金桔茶或带叶苦橙走。 |
| 蓝莓、可可、酒酵感 | 蓝莓可以偏冷冻莓果、醋栗，也可以偏莓果酱。可可可以往可可粉、黑巧或巧克力饼干走。两者与酒香放一起，可以想到酒渍樱桃、黑莓果酒或酒心巧克力。 |
| 榛果、焦糖 | 烤榛果、坚果酥、黄油司康和焦糖脆片可以串成一组。沿着焦糖继续想，可以走到太妃糖、烤布丁的脆壳或红糖边缘的一点焦香。 |

## 示例一｜默认长日记

输入：巴拿马水洗瑰夏。茉莉花、麝香葡萄、白桃、白茶、蜜橘。

> 🪽｜巴拿马水洗瑰夏
>
> 茉莉、麝香葡萄、白桃。白色 floral，白色白色。这个茉莉很幽，像刚开一点的白花，也像茉莉银针里一丝丝贴着茶叶的香，还有一点玉兰花苞的意思。极度细，极度细。麝香葡萄也带一点花似的香，细想是贴着葡萄皮的那种，跟茉莉放在一起非常自然。
>
> 麝香葡萄的果香就很亮了。霜感白葡萄、刚切的香梨，一丝丝荔枝水？有点像白葡萄酒里那股果皮香，水润，带一点活泼的酸。白桃的甜更软，像熟白桃切开，桃肉的甜，靠近皮还有一丝清清的果酸。葡萄亮，白桃软，漂亮漂亮。
>
> 白桃这个软甜特别衬白茶。像一口白桃冷泡茶，桃肉、一点洋槐蜜，底下还是淡淡的茶汤。甜得很细，像一小勺蜜在水里化开，香气浮在茶汤上，薄薄一层。就是这种软里还有一点清清爽爽的茶感，很有教养，很有教养。
>
> 蜜橘把这份软甜提亮了。黄颜色的酸，轻轻跳一下。像橘瓣里溅出来的一点果汁，也像剥开皮时散出来的橘皮香，橙花蜜，糖渍橘瓣？甜里一直有一点亮。它跟麝香葡萄都亮，葡萄是白色的亮，蜜橘是黄颜色的亮。好漂亮的黄啊。
>
> 蜜橘这点黄和白茶摆在一起，让我想到午后坐在窗边喝茶。杯子挪到太阳下面，茶汤里一层很浅的金色，手边剥着蜜橘，茶香里还是一丝丝茉莉。太阳照进来的感觉就是这杯的甜，薄薄的、暖暖的。我愿意在那儿多坐一会儿。
>
> 白茶，白茶。细想我最舍不得的是白茶里贴着的那一点茉莉，闻着像花，回想起来还有茶的清甜。白桃很软，蜜橘很活泼，整杯最让我想再喝一口的还是这个很幽、很细、白色白色的花香。怎么这么好闻啊。

## 示例二｜有优点也有涩感

输入：埃塞俄比亚日晒。高温蓝莓和可可，中温有一点酒酵感，尾段微涩。写三小段。

> 高温蓝莓、可可。蓝莓有点像捏破了皮的那一颗，酸香亮亮的，可可在旁边是深色的干香。两个合起来像蓝莓沾了一层可可粉。漂亮，深紫色的漂亮。
>
> 中温有一丝酒酵感。它跟前面那两样放在一起，很像蓝莓酒心巧克力，刚才脑子里还是可可粉，现在想到的是那一小口莓果酒。酒酵轻轻一下，有点意思。
>
> 尾段微涩，舌面稍稍收了一下，像吃到最后还留一点可可粉的干感。这个收尾跟开头的可可接得上。最喜欢的还是蓝莓跟可可挨着那一下，好漂亮。

## 示例三｜只有少量风味词

输入：红茶、青梅、清亮的酸。两三句。

> 青梅、红茶，青梅是刚切开那一下的酸，清清亮亮，好漂亮的青色酸。红茶在底下稳稳的，像一口梅子红茶，梅酸亮一下，茶汤轻轻把它接住。漂亮，漂亮。
