# 口吻和示例

## 口吻特点

| 表达习惯 | 写新豆子时怎么用 |
| --- | --- |
| 从李子、清酒、花香一路写到白衬衫和钟鼎之家 | 先钉住香气和质地，再把它们写成某种人的气质。甜香温暖可以大方，白花幽可以慢热，尖酸也可以调皮或有脾气。 |
| 同一个词反复回来，有时前面还叠着「极度」或「超级无敌」 | 在气味重现、情绪上来或某个词实在贴切的时候重复。短句可以独占一行，长串里也可以突然冒出来。 |
| 风味有颜色、光和触感。写白色的酸、霜感红葡萄、奶呼呼 | 颜色随风味和强弱变化，触感随已知的口感变化。「暖」「冷」可以形容甜的感觉，实际杯温按输入写。 |
| 白葡萄酒、甜点、香水、茶、室内暖气和海风会出现在同一篇里 | 挑一两个能说清差异的跨感官联想。联想越具体，越要贴住杯里的线索。 |
| 夸张地赞叹，也承认苦、酵和掐喉感 | 允许喜欢和嫌弃发生在同一口，保留用户记下的持续时间与强弱。 |
| 感叹、反问、零碎英语、顺手记参数和感谢朋友 | 感叹和英语跟着情绪走。参数与人情按用户的真实素材自然插入。 |

## 风味怎么接着往下写

按这支豆子的酸甜、香气和口感挑方向。下面的例子可以拆开用。

| 原有风味 | 可以往哪里想 |
| --- | --- |
| 茉莉花、白茶 | 白花的幽香可以想到栀子花苞、玉兰和淡淡的茉莉银针。茶感可以想到茶汤里的清甜、梨皮和一点干草香。 |
| 白桃、麝香葡萄 | 可以顺着水果的水润感想到水蜜桃、香梨、荔枝水、霜感白葡萄。沿香气可以联想到麝香葡萄汁、白葡萄软糖和一口白葡萄酒。 |
| 蜜橘、西柚 | 蜜橘从果汁往橘皮糖、橙花蜜和汽水走。西柚从果肉的酸往柚皮微苦、金桔茶或带叶苦橙走。 |
| 蓝莓、可可、酒酵感 | 蓝莓可以偏冷冻莓果、醋栗，也可以偏莓果酱。可可可以往可可粉、黑巧或巧克力饼干走。两者与酒香放一起，可以想到酒渍樱桃、黑莓果酒或酒心巧克力。 |
| 榛果、焦糖 | 烤榛果、坚果酥、黄油司康和焦糖脆片可以串成一组。沿着焦糖继续想，可以走到太妃糖、烤布丁的脆壳或红糖边缘的一点焦香。 |

## 示例一｜默认长日记

输入：巴拿马水洗瑰夏。茉莉花、麝香葡萄、白桃、白茶、蜜橘。

> 🪽｜巴拿马水洗瑰夏
>
> 茉莉花、白桃、麝香葡萄，白色 floral，白色白色。那一点茉莉特别幽，像茉莉银针、白玉兰花苞，还有一点点梨花？极度轻。像夏天有人把白衬衫洗完晾在院子里，天还没黑，风已经把那个人身上的香气吹过来了。我都没有看见人。
>
> 麝香葡萄，麝香葡萄。果汁是亮的，脑子里从霜感白葡萄走到荔枝水、青梨、带一点皮香的长相思。又像葡萄软糖刚撕开，薄薄的一层果香先扑到鼻子上。葡萄好漂亮哦，甜得很有主见，谁来都劝不住它这么漂亮。
>
> 白桃跟白茶坐在一起，是很有教养的甜。像白桃冷泡茶，桃肉、桃皮、一小勺淡淡的洋槐蜜。仔细想又像在一块桃子奶油蛋糕旁边放了杯白茶，茶汤把嘴里的甜轻轻收了一下。好软，好软。就是我平常很不耐烦的人，如果她今天身上是这个味道，我会听她讲完。
>
> 还有蜜橘！橘瓣、橙花蜜，黄黄的，活泼的，一点像金桔茶里的橘皮糖，一点像橘子汽水刚开瓶那股轻轻冲上来的气。甚至有一丝糖渍柚子皮？黄颜色的甜里有一笔明亮的酸。像本来大家在安静喝茶，忽然有个小孩从门缝里探头，手里捏了两瓣橘子，非要分你一瓣。
>
> 茉莉又把我拉回去了。白色花、白色葡萄、白桃皮，那种幽香让我想到午睡醒过来，窗边有杯茶，隔着一点距离还能闻见。那点橘甜又像衣袋里藏了颗橘子糖，摸得到糖纸，舍不得剥。嗯哼？？我怎么连喝个咖啡都能对一颗想象中的橘子糖产生感情。
>
> 白茶，白茶。整杯最让我惦记的还是那点茶香里轻轻贴着的茉莉。像刚把窗关上，又想起来外面那股风很好闻，于是打开一点，就一点。好漂亮，好想再喝一口。

## 示例二｜有优点也有涩感

输入：埃塞俄比亚日晒。高温蓝莓和可可，中温有一点酒酵感，尾段微涩。写三小段。

> 高温蓝莓，可可。漂亮的深紫色，像一颗蓝莓掉进了一层可可粉里。莓，莓，怎么这么莓啊。
>
> 中温一丝酒酵感出来，有点像蓝莓在酒心巧克力里多坐了一会儿。热的时候我还在想这杯挺端庄的，诶，现在它开始说真心话了。
>
> 尾段轻轻收一下，有一点涩。诶，穿丝绒外套的人怎么说完话还捏了一下我袖口。

## 示例三｜只有少量风味词

输入：红茶、青梅、清亮的酸。两三句。

> 红茶、青梅，好漂亮的青色酸。青梅像穿着硬底小皮鞋在舌尖走了两步，哒、哒，酸得我都坐直了。红茶在旁边很稳，青梅还在哒哒哒。
