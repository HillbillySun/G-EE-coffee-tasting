# G-EE-coffee-tasting

读 [口吻和示例](references/voice-and-examples.md)，按用户给的豆子资料直接写成品。默认写约 550–850 字的中文长日记，分成松散的几段。只给一两个风味词也按长日记写。用户指定篇幅、台卡或社媒短稿时，按用途调整。

## 先抓住这支豆子的味道

- 从用户的风味、酸甜苦、口感和余韵里挑出一两个最有辨识度的感官线索，让它们在文中回来。保留决定整体印象的特征和用户明确写出的瑕疵。保留原有豆名、年份、处理法和冲煮参数的含义。
- 有开袋、磨粉、注水或温度记录时，按用户给出的体验顺序写出变化。只有风味表时，按香气、质地和联想组织句子，具体温区、出现先后和留香时长以用户所给信息为准。只有豆名或规格时，问一句有没有风味或杯中印象。

## 让风味一串串长出来

- 从每个主要风味沿着香气、酸甜、口感或余味挑一两条路，多走几步。写同类的细微变化，也写可能伴随出现的味道。譬如蜜橘可以沿酸香走到橙花、黄柚皮和橘子汽水，再沿甜感走到糖渍橘瓣、橘皮蜜饯和柑橘蜂蜜。可以让两个主调汇合，白桃和白茶放在一起就能想到白桃冷泡茶、桃皮和茶汤里的淡蜜香。
- 一篇里铺开几组风味。让相邻水果、花、茶、酒、糖果、甜点或香料成串出现，沿着当前豆子的味道选材。先把一串写到具体，再突然跳到颜色、触感或一个生活画面。之后回到前面提过的某个味道，给它换个角度，像她重新想了一遍又说了出来。
- 用户给的风味可以直说。添进去的近邻风味可以像她那样一整串轻轻猜过去，比如「还有一丝黄柚皮？糖渍橘瓣？」「有点往桃皮、梨花、荔枝水那边走」。一个「像」「好像」「我想到」可以领起整串。根据已有风味选择联想的方向，杯测事实、参数、真实经历和人情来往以用户给的信息为准。

## 按她的节奏落笔

1. 从名词串或一句突发感叹起手。让几项风味挤在一行，再用短句急停。豆名适合单独一行，资料没有豆名时直接开写。
2. 让风味突然变成画面或人物。挑一个这支豆子能撑住的细节，比如杯沿留下的白茶香像一件白衬衫上隔夜的淡香，果酸像有人在走廊上踩了两下皮鞋。写完跳回舌尖、香气或余味。
3. 在全篇情绪最高的一处重复关键词，让它变成口头禅。「漂亮，漂亮」「好酸，好酸！」「这一口有点过分了」都可以，随豆子换词。用少量顺手的 `floral`、`spicy`、`silky`、`body` 或英文感叹，搭一两句人话或半截话。给句子留点毛边和空拍。
4. 收尾留给一口余韵、一句自问或一句很短的心情。原笔记里的 🪽、爱心和话题标签按场合选用。按用户指定的语言与豆名写法出稿，纯中文稿用中文风味词。默认交一版正文。

出稿前看一遍。每段是否带来了新味道、新层次或新画面？联想串能否追回原本的风味？用户给出的苦、涩、酵感或先后顺序是否保留？默认长稿要有她念念叨叨、喝到哪想到哪的分量。正文直接交付。
